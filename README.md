# 🚀 Featured Projects

### 🛒 [E-Commerce API](https://github.com/team-5-backend/e-commerce-api)

A modular Express.js REST API with **40+ documented operations** covering authentication, products, search, carts, wishlists, orders, reviews, users, and admin analytics.

- JWT authentication, OTP verification, HTTP-only refresh-token cookies, sessions, and role-based authorization
- Redis caching, request validation, rate limiting, and security middleware
- Cloudinary image uploads and Stripe, PayPal, and Paymob payment workflows with webhooks
- Docker support and interactive [API documentation](https://e-commerce-api-blond-eta.vercel.app/api/v1/docs)

### 🛍️ [E-Commerce Platform](https://github.com/team-9-frontend/e-commerce)

A team-built **Turborepo monorepo** containing customer storefront and admin applications built with **React 19, Vite, Tailwind CSS, and TanStack Query**.

- Product and category management, authentication, cart functionality, responsive layouts, and Stripe checkout
- Shared UI, API, and utility packages across the applications

### 🛍️ [Next.js E-Commerce Store](https://github.com/ziad-wdev/Store)

A modern storefront built with **Next.js 16, React 19, TypeScript, Redux Toolkit, RTK Query, and Tailwind CSS**.

- Product search, filtering, pagination, product details, cart, and wishlist functionality
- Persistent client-side state using Redux Persist
- [Live demo](https://store-two-mu.vercel.app/)

### 💼 [Personal Portfolio](https://github.com/ziad-wdev/portfolio)

A responsive portfolio built with **Next.js 16 and TypeScript**, using the GitHub API and Microlink API for dynamic project content, plus an EmailJS contact system with TanStack Form.

- [Live portfolio](https://ziad-wdev.vercel.app/)
